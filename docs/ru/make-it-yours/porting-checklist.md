# Чек-лист переноса

> [!NOTE]
> **Машинный перевод, требует проверки**
>
> Эта страница переведена автоматически. Обязательным является английский текст. Как прислать
> исправление перевода: [Переводы](../../en/contributing/translations.md#send-your-work).

Весь путь от "автомобиля, который никто не измерял" до "устройство работает вместо CAN-адаптера" на
одной странице. Идите сверху вниз. Каждая строка говорит, когда шаг выполнен. Не пропускайте
строку только потому, что другой автомобиль "наверное" работает так же: каждому факту о вашем автомобиле
нужен статус, **измерено** (measured) или **не проверено** (unverified).

По ходу записывайте результаты в копию `vehicles/_template/README.md`. Команды с `tools/`
выполняются из папки, указанной в строке: из папки репозитория или из `firmware`.

> [!CAUTION]
> **Ничто в этом списке не передаёт в шину автомобиля**
>
> Каждая сборка здесь только слушает шину CAN автомобиля. Ваш собственный профиль вообще нельзя
> собрать с передачей. Передача для нового автомобиля — отдельный проект со своими правилами:
> [Передача в шину CAN](../../en/safety/transmit.md).

## 3. Сигналы {#3-signals}

Расшифровывайте только то, что нужно. По порядку полезности:

| Сигнал | Выполнен, когда | Для чего |
|---|---|---|
| Состояние зажигания и двигателя | байт и значения для выкл. / вкл. / двигатель работает, видны в трёх повторах; [период кадра](decode.md#how-often-a-frame-comes) известен (должен быть меньше 1 с) | ACC для магнитолы |
| Задний ход | байт.бит, виден три раза | выход заднего хода (камера) |
| Фары | байт.бит; [период кадра](decode.md#how-often-a-frame-comes) известен (должен быть меньше 1 с) | выход подсветки |
| Кнопки на руле | один шаблон байт.бит на кнопку, ни один не присутствует в покое | кнопки для магнитолы |
| Ручки | байт счётчика, направление на щелчок | следующий / предыдущий |
| Парктроники | статус, зоны от 0 до 7 на датчик, запрос звука, интервал, если автомобиль его отправляет; [период кадра](decode.md#how-often-a-frame-comes) (должен быть меньше 400 мс) | зуммер, картинка датчиков на магнитоле |
| Двери, багажник, капот (необязательно) | по одному биту на дверь, каждая дверь видна открытой и закрытой | картинка дверей на магнитоле |
| Наружная температура, климат-контроль, экономичный режим, настройки, бортовой компьютер (необязательно) | байт и масштаб каждого значения, сверенные с дисплеем самого автомобиля | соответствующие экраны магнитолы |

Каждый сигнал попадает на страницу автомобиля со своим кадром, `байт.бит`, значениями, статусом и
шагом записи, который его показал. Как это делать, показывает [Расшифровка кадров](decode.md).
