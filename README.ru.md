# ESPCanBox

Открытое устройство на ESP32-S3, которое стоит между шиной CAN автомобиля и магнитолой на
Android и может заменить CAN-адаптер, который продаётся вместе с магнитолой.

## Для кого это

Для любителей, которые умеют паять небольшую плату, пользоваться мультиметром и собирать
прошивку в PlatformIO (в руководствах показана каждая команда). Что вы получите, зависит от
автомобиля и магнитолы:

- **Peugeot 508 SW (PSA AEE2010) с магнитолой на Android, которая работает по протоколу «XP»:**
  устройство может заменить CAN-адаптер: кнопки, парктроники, бортовой компьютер и питание
  магнитолы.
- **Любой другой автомобиль:** слушайте и записывайте шину CAN (сборка `listen_generic_wifi`),
  затем расшифруйте её и напишите собственный профиль автомобиля по руководствам
  [Под свой автомобиль](docs/ru/make-it-yours/porting-checklist.md). Магнитоле ничего не
  отправляется, пока вашего профиля нет.
- **Любая другая магнитола:** пока «XP» — единственный протокол магнитолы. Для другой
  магнитолы нужен новый протокол в прошивке ([Сопоставление с магнитолой](docs/ru/make-it-yours/radio-mapping.md)).

## Что оно делает

- **Слушает шину CAN автомобиля** и никогда не передаёт в сборках по умолчанию. Код передачи
  есть только в отдельной сборке `decoder_tx_wifi`; скрипт проверяет это после каждой сборки.
- **Подаёт звуковые сигналы парктроников** через свой небольшой динамик.
- **Общается с магнитолой** в режиме декодера, как это делал CAN-адаптер: кнопки на руле и на
  центральной панели, отображение парктроников, бортовой компьютер, наружная температура,
  состояние климат-контроля, двери и настройки автомобиля.
- **Переключает три линии 12 В** для магнитолы в режиме декодера: ACC (питание магнитолы),
  подсветка, задний ход.
- **Веб-панель** через собственную сеть Wi-Fi: состояние, кадры CAN в реальном времени,
  консоль, запись, обновление прошивки. Языки панели: английский, польский, немецкий,
  испанский, русский, украинский (последние четыре — машинные переводы, требуют проверки).
- **Консоль USB** с фиксированным форматом строк, который читают инструменты
  (см. [Консоль](docs/en/reference/console.md)).
- **Профили автомобилей и протоколы магнитол выбираются при сборке:** `psa_aee2010`
  (эталонный автомобиль) или `generic` (любой автомобиль, только прослушивание); протокол
  магнитолы `XP` или `NONE`. Шаблон для вашего автомобиля лежит в `firmware/lib/car_example`
  (см. [Напишите профиль](docs/ru/make-it-yours/write-a-profile.md)).
- **Тесты всей логики на вашем компьютере**, на записях из автомобиля, без железа
  (см. [Тесты на компьютере](docs/en/testing/host-tests.md)).
- **Необязательная сборка с передачей** (`decoder_tx_wifi`): по умолчанию она может отправлять
  только один кадр — запрос настроек автомобиля `15B` (проверяется только по ID и длине), и
  только после того, как вы разрешите передачу. Пробный кадр `1A9` есть только в сборке с
  `-DCAN_TX_EXPERIMENTAL=1`. Управление климат-контролем с магнитолы таким способом **не**
  заработало. Подробности: [Передача в шину CAN](docs/en/safety/transmit.md).

Состояние: версия 2.0.0 компилируется, проходит тесты на компьютере, проверена на стенде на плате ESP32-S3-WROOM-1-N16R8 и опробована в одном автомобиле 20.11.2026, включая глубокий сон и пробуждение от шины.

## Поддерживаемые автомобили

| Автомобиль | Профиль прошивки | Статус |
|---|---|---|
| Peugeot 508 SW, 2015 (PSA AEE2010) | `psa_aee2010` | измерено (measured) на одном автомобиле |
| любой автомобиль | `generic` (сборка `listen_generic_wifi`) | только прослушивание: записывает кадры, ничего не отправляет магнитоле, выходы 12 В выключены |

На эталонном автомобиле шина у магнитолы работает на 125 кбит/с (измерено). Напряжения на ней
похожи на низкоскоростную отказоустойчивую CAN (CANH около 0,65 В, CANL около 4,5 В в среднем
при включённом зажигании); это ещё не подтверждено осциллографом. Подробности:
`vehicles/peugeot-508-sw-2015/README.md` и `vehicles/SUPPORTED.md`.

## Поддерживаемые магнитолы

| Протокол магнитолы | Прошивка | Статус |
|---|---|---|
| «XP» (протокол CAN-адаптера Simple Soft, магнитола на Android на платформе FYT, профиль CAN "XP Simple Soft -> Peugeot 508 -> Type 2") | `-DRADIO_PROTOCOL=XP` | измерено на одной магнитоле (записи UART адаптера и магнитолы) |
| без магнитолы | `-DRADIO_PROTOCOL=NONE` | по UART ничего не отправляется |

Описание протокола, только по записям: `radios/xp-simple-soft/protocol.md`.

## Быстрый старт

Так устройство заработает у вас на столе, без автомобиля. Нужна плата ESP32-S3 с 16 МБ
флеш-памяти и 8 МБ PSRAM (N16R8) и кабель USB. Полное руководство:
[Быстрый старт](docs/ru/quick-start/flash.md).

1. **Прочитайте [Безопасность](docs/ru/getting-started/safety.md).** До этого ничего не
   ставится в автомобиль.
2. **Установите инструменты.** Установите [uv](https://docs.astral.sh/uv/); он запускает
   PlatformIO без отдельной установки. Git for Windows (Git Bash) для прошивки не нужен: он
   нужен для тестов на компьютере и для страниц раздела «Под свой автомобиль» (свой автомобиль
   или своя магнитола).
3. **Соберите и прошейте сборку только для прослушивания с веб-панелью.** Введите это в корневой
   папке репозитория (в Windows — в PowerShell):

   ```
   uvx platformio run -d firmware -e listen_wifi -t upload
   ```

4. **Откройте консоль USB** (115200 бод), например
   `uvx platformio device monitor -d firmware`. Вводимые символы не видны; после каждой команды
   нажимайте Enter. Введите `ver`, затем `stat`, затем `wifi` (имя
   сети) и `wifi showpass` (пароль).
   Не оставляйте пароль в логах, которыми вы делитесь.
5. **Откройте панель.** Подключите телефон или ноутбук к сети Wi-Fi устройства (её имя выводит
   `wifi`), откройте `http://10.50.8.1` и войдите с этим паролем. Язык выберите на экране
   входа.

Для другого автомобиля, не эталонного, потом используйте `listen_generic_wifi`.

Дальше: [Проверка на стенде](docs/ru/quick-start/bench-test.md), затем
[Под свой автомобиль](docs/ru/make-it-yours/porting-checklist.md) для другого автомобиля или
[Установка в автомобиль](docs/en/install-in-car/checklist.md) для эталонного автомобиля.

Платы ещё нет? Макет устройства запускает панель на вашем компьютере с записью:
`python -I firmware/tools/mock_device.py firmware/test_data/captures/can_20261111_191045.log`
(в Linux и macOS: `python3`; см. [Первый запуск](docs/ru/quick-start/first-boot.md)).
